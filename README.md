# نظام إدارة العلاوات والترفيعات الوظيفية

## 📋 نظرة عامة
نظام متكامل وشامل لأتمتة وحوسبة العمليات المعقدة المتعلقة بحساب العلاوات السنوية والترفيعات الوظيفية لجميع الموظفين.

## ✨ المميزات الرئيسية

### 1. إدارة شؤون الموظفين
- ✅ إضافة وتعديل بيانات الموظفين
- ✅ تتبع الدرجات والمراحل الوظيفية
- ✅ حفظ المؤهلات العلمية والعناوين الوظيفية
- ✅ نظام مؤشرات تتبع العلاوات الذكي

### 2. محرك الحسابات الذكي
- ✅ حساب تلقائي للعلاوات والترفيعات
- ✅ تأثير ديناميكي للأحداث المهنية
- ✅ تتبع دقيق للتواريخ
- ✅ معالجة الحالات الخاصة (مثل ترفيع الدبلوم السريع)

### 3. إدارة الأحداث المهنية
- ✅ كتب الشكر والتقدير
- ✅ العقوبات (لفت نظر، إنذار، توبيخ)
- ✅ الإجازات (أمومة، بدون راتب، إلخ)
- ✅ الشهادات العلمية
- ✅ نظام إلغاء العقوبات بكتب الشكر

### 4. لوحات المتابعة
- ✅ لوحة الاستحقاقات القادمة (أسبوع/شهر)
- ✅ لوحة الإحصائيات الشاملة
- ✅ تقارير مفصلة حسب التصنيفات

### 5. نظام إصدار الأوامر الإدارية
- ✅ إنشاء تلقائي للأوامر الإدارية
- ✅ تصدير إلى Word و Excel
- ✅ صيغة معتمدة ومتوافقة

## 🚀 التثبيت والتشغيل

### المتطلبات
- Python 3.8 أو أحدث
- PyQt5
- python-dateutil

### خطوات التثبيت

1. **تثبيت المتطلبات:**
```bash
pip install -r requirements.txt
```

2. **تشغيل التطبيق:**
```bash
python main.py
```

## 💾 قاعدة البيانات

يستخدم النظام قاعدة بيانات SQLite محلية تحتوي على:
- جدول الموظفين
- جدول الأحداث المهنية
- جدول تاريخ العلاوات والترفيعات
- جدول سلم الرواتب

## 🔧 التخصيص

يمكن تخصيص النظام من خلال:
- تعديل سلم الرواتب في قاعدة البيانات
- تعديل قواعد الحسابات في محرك الحسابات
- تخصيص الألوان والتصميم

## 📊 سلم الرواتب

النظام يدعم سلم الرواتب من الدرجة 1 إلى 10 مع 11 مرحلة لكل درجة.

### قواعد الترفيع:
- الدرجات 10-6: 3 علاوات + 1 ترفيع (4 سنوات)
- الدرجات 5-2: 4 علاوات + 1 ترفيع (5 سنوات)
- الدرجة 1: 10 علاوات بدون ترفيع
